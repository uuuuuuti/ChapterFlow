## 5. 每个工作包的完成定义

一个工作包只有同时满足以下条件才能从“进行中”改为“待验收/已验收”：

- 有对应原生路由和真实操作，不是占位卡片、整页旧 Workspace 或只读假数据。
- 正常、空、加载、失败、刷新恢复、无 AI 和需要时的并发状态都有处理。
- 有契约/API/服务测试和对应 React 单测；涉及导航的行为有四视口 E2E。
- AI 结果先成为候选，作者动作明确后才写入正式正文/设定；任务可离页恢复。
- 没有普通入口指向 `/shelf`、`/projects/*` 或旧品牌；旧深链只经解析器并保留上下文。
- 迁移矩阵写明源码、接口、测试命令、实际结果、截图或限制。
- 运行 `npm run verify`；失败、跳过和外部条件逐项记录，不扩大 skip。

## 6. 不得改变的边界

- 不自动上传或发布到起点、番茄、个人站点等第三方平台。
- 不删除或改名既有 `/api/projects/*`、`/api/runs/*`、`/api/autopilot/*` 等服务契约，除非单独提供兼容迁移。
- 不清理用户参考图、未识别工作树改动和现有截图产物。
- 不把模拟 AI 输出描述为真实模型质量，不泄露模型密钥。
- 不通过删除历史测试、放宽断言、扩大环境 skip 或把异常跳回首页来宣称迁移完成。
