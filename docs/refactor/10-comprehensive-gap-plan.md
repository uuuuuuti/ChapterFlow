### M2：作品库、三种开书方式和导入恢复

#### 手工开书

原生页面可以创建书名和简介，`BookProfileInput` 也已接入手工与 AI 建书请求；需要继续把题材、目标读者、核心承诺、风格、篇幅、更新节奏、结局方向、禁区等字段形成可恢复的正式流程。需要：

- `/books/new?mode=manual` 现在按模式保存可恢复的本地档案草稿，刷新/返回后会恢复题材、承诺、节奏、目标字数、边界、世界规则和长线弧光，服务端创建成功后清理草稿；仍需把 local/server 模式切换和重复书名冲突做成正式回执。
- 重复书名、空库、表单离开、网络失败、切换 local/server 模式有明确提示和重试。
- 创建成功后从作品首页继续到大纲和第一章，不经过旧 Shelf/Overview。

#### AI 开书

三份完整方案、局部编辑、互斥单选、整组放弃、任务轮询和失败反馈已有首版。仍需：

- 方案 payload 绑定生成时的项目、档案、指南针和初始大纲版本；候选不能被另一个作品或旧版本误用。
- 方案采用结果写入哪些字段要显示清楚，保存 source run、candidate id、基线版本和作者裁决时间；撤销或回到候选必须可追溯。
- 方案字段缺失、模型输出不完整、重试和离页刷新不能伪造默认内容。
- 三份方案的差异应按卖点、主角、核心冲突、长线方向、首卷和风险并排显示，而不是只显示 JSON。

#### 导入

原生导入已建立临时作品上下文，支持分块上传、hash、恢复键、UTF-8/GB18030、空稿拒绝、解析异常分类、错误类别/修复动作回执、预览、分析任务、失败重试、取消和临时作品清理。仍需：

- 文件损坏按“无法解码、格式损坏、结构不完整、超限、hash 不匹配”分类，服务端错误 envelope 返回 `failureKind`、`repairAction` 和 `retryable`，原生错误注记会显示对应修复动作；仍需在导入页把重新选择文件/恢复上传直接做成操作按钮。
- 相同 hash 给出“打开已有批次 / 继续创建副本 / 取消”选择，不只是一条提醒。
- 分析部分成功时按章节、人物、事实、伏笔、时间线显示成功/失败/待重试；应用只提交勾选项，失败不能留下半个正式作品。
- 应用前显示创建/更新/跳过数量和冲突；应用后回到新作品、章纲和正文定位。
- 放弃、取消、过期批次和浏览器刷新要清理恢复键、临时作品和未完成上传会话。

## 5. 统一技术约定

### ID 和来源

- `projectId` 指作品；`outlineNodeId` 指大纲节点；`documentId` 指正文文档；`documentVersionId` 指不可变正文版本；`runId` 指一个后台任务；`sessionId` 指连续创作航次；`selection` 只表示文档版本内的字符范围。
- 任务 `origin` 必须同时保存 surface、project/document/outline/run/session、selection、版本和专项检查问题 ID（存在时）。URL 只传稳定 ID，不传完整正文或 JSON。

### 候选和作者确认

- AI 正文、修订、章纲、设定变化、开书方案均先落候选；候选保存 source run、基线版本/hash、生成时间、updatedAt 和作者决策。
- 任何采用接口都要在事务内校验 `expectedVersion`、`expectedUpdatedAt`、`sourceHash` 或 `baseVersionId`；冲突响应带远端快照和可比较内容。
- 过期候选只读，可重新生成或打开差异；不得静默覆盖本地草稿或锁定事实。

### 错误和缓存

- API 错误使用稳定 code、中文 message、HTTP status 和必要的 details；details 不泄露密钥。
- 写入成功后精准更新/失效实体和派生列表；错误保留表单与用户输入，提供重试、读取最新、保留本地或安全返回。
- 终态任务停止轮询；未知状态显示诊断、重新读取、复制诊断和日志下载。

### 迁移、备份和兼容

- 每个新迁移说明版本、旧库默认值、索引/FK、备份恢复兼容和回滚策略；不得修改既有 API 契约的语义。
- 作品备份保存正文版本、草稿、设定、任务来源和迁移信息；系统备份只在 server 能力存在时显示恢复目录操作。
- 不删除用户参考图、未知工作树改动、历史测试和已有截图产物。

### 发布边界

- 只实现质量检查、范围选择、预览、导出、批次记录、备份和作者手工发布记录。
- 不登录、不保存第三方账号、不自动上传到番茄、起点或个人站点。

## 6. 每个 Goal 的完成定义

一个工作包只有同时满足以下条件，才可以在矩阵中从“进行中”改为“待验收”或“已验收”：

- 正常、加载、空、失败、刷新恢复、无 AI 和必要并发路径都有测试。
- AI 结果先候选，作者动作明确后才写入正文/设定；长任务离页后仍由服务端状态恢复。
- 普通渲染树没有旧路径和旧品牌；旧地址只经解析器并保留上下文。
